# Ep.1 술래잡기 — Minecraft JE 26.2

Paper 26.2 / Java 25용 플러그인입니다.

## 명령어
- `/게임 시작` 게임 시작
- `/게임 끝` 게임 즉시 종료
- `/게임 시간` 테스트용으로 남은 시간을 16:00으로 변경

## 빌드
Java 25와 Gradle이 필요합니다.

```bash
gradle build
```

생성 파일: `build/libs/SulJab-1.0.0.jar`

GitHub에 올리면 `.github/workflows/build.yml`이 자동으로 JAR를 빌드하고 Artifact로 제공합니다.
